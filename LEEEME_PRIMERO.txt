¿QUÉ CAMBIÓ?
============

Tu contraseña ahora:
✅ Funciona en cualquier navegador (Chrome, Firefox, Edge, etc)
✅ Funciona aunque cambies la ruta del archivo HTML
✅ Puedes exportar/importar para llevar entre dispositivos
✅ Se guarda cifrada de forma segura (PBKDF2-SHA256)

---

PRIMEROS PASOS
==============

PASO 1: Abre Opciones.html
PASO 2: El sistema te pedirá crear una contraseña
PASO 3: Ingresa tu contraseña y confirma
PASO 4: ¡INMEDIATAMENTE haz clic en 📥 Exportar y guarda el archivo!
PASO 5: Listo usando la página normalmente

---

LOS 3 BOTONES NUEVOS EN OPCIONES
=================================

📥 EXPORTAR
  ├─ Qué: Descarga un archivo con tu contraseña cifrada
  ├─ Cuándo: Cuando quieras hacer backup o cambiar de dispositivo
  └─ Cómo: Haz clic → Se descarga automáticamente

📤 IMPORTAR
  ├─ Qué: Carga una contraseña de un archivo guardado
  ├─ Cuándo: Cuando cambias de navegador o dispositivo
  └─ Cómo: Haz clic → Selecciona archivo → Actualiza página

🔒 CAMBIAR
  ├─ Qué: Cambia tu contraseña actual a una nueva
  ├─ Cuándo: Por seguridad o si quieres contraseña diferente
  └─ Cómo: Haz clic → Ingresa contraseña actual → Nueva contraseña

ESCENARIOS COMUNES
==================

ESCENARIO 1: Quiero usar TANTO Chrome COMO Firefox
───────────────────────────────────────────────────
1. Chrome: Abres Opciones.html
2. Chrome: 📥 Exportar → Guarda el archivo
3. Firefox: Abres Opciones.html (mismo PC, misma ruta)
4. Firefox: Pide crear contraseña (primera vez en Firefox)
5. Firefox: 📤 Importar → Selecciona tu archivo
6. ✅ Firefox ahora reconoce tu contraseña


ESCENARIO 2: Cambié la ruta del archivo HTML
──────────────────────────────────────────────
De: C:\Users\Edwin\Desktop\SUIC Data\Opciones.html
Para: D:\Documentos\MiProyecto\Opciones.html

1. Abre Opciones.html en la nueva ruta
2. ✅ Sistema automático reconoce tu contraseña
3. Pide ingresar contraseña (NO crea una nueva)
4. ¡Listo!


ESCENARIO 3: Cambié de computadora
───────────────────────────────────
Computadora Vieja:
1. Abre Opciones.html
2. 📥 Exportar → Descarga archivo
3. Guarda en pendrive / email / nube

Computadora Nueva:
1. Copia los archivos de SUIC Data
2. Abre Opciones.html
3. Pide crear contraseña (primera vez)
4. 📤 Importar → Selecciona tu archivo
5. Actualiza página
6. ✅ Contraseña importada


ESCENARIO 4: Olvide mi contraseña
──────────────────────────────────
✅ Si tienes archivo de export:
   1. F12 → Storage → IndexedDB → SUIC_CONFIG → Delete
   2. Recarga página
   3. Pide crear contraseña nueva
   4. 📤 Importar → Selecciona tu backup
   5. ✅ Contraseña original restaurada

❌ Si NO tienes backup:
   1. F12 → Storage → IndexedDB → SUIC_CONFIG → Delete
   2. Recarga página
   3. Tendrás que crear una nueva contraseña
   4. 📥 INMEDIATAMENTE Exporta para no perderla

CONSEJOS DE SEGURIDAD
=====================

✓ Crea una contraseña FUERTE
  - Mezcla mayúsculas, minúsculas, números y símbolos
  - Mínimo 12 caracteres
  - No uses fechas personales ni palabras comunes

✓ Exporta tu contraseña APENAS la crees
  - 📥 Exporta con el botón
  - Guarda en 3 lugares: nube, pendrive, email

✓ NO COMPARTAS tu archivo de export
  - Es como compartir tu contraseña
  - Guarda en lugar seguro

✓ Si compartes ese PC con otros
  - Limpia caché y cookies periódicamente
  - Usa navegador diferente por usuario

PRUEBAS RÁPIDAS
===============

TEST 1: ¿Funciona el cambio de navegador?
──────────────────────────────────────────
1. Chrome: Crea contraseña
2. Chrome: 📥 Exporta y guarda
3. Firefox: 📤 Importa el archivo
4. ✅ Firefox pide tu contraseña original y abre

TEST 2: ¿Funciona el cambio de ruta?
─────────────────────────────────────
1. Mueve carpeta SUIC Data a otra ubicación
2. Abre Opciones.html desde el nuevo lugar
3. ✅ Pide tu contraseña (no crea una nueva)

TEST 3: ¿Funciona exportar/importar?
────────────────────────────────────
1. 📥 Exporta → descarga archivo
2. Limpia datos (F12 → Storage → IndexedDB → Delete)
3. Recargas página (pide crear contraseña)
4. 📤 Importas el archivo descargado
5. ✅ Tu contraseña original se verifica

EMERGENCIAS / PROBLEMAS
=======================

PROBLEMA: "Dice que mi contraseña es incorrecta"
SOLUCIÓN:
  ├─ ¿Es la contraseña correcta? (a veces caps lock está activo)
  ├─ ¿Tengo un backup exportado? → 📤 Importar
  └─ ¿Sin backup? → Limpiar datos y empezar (ver GUIA_RAPIDA.md)

PROBLEMA: "No puedo importar el archivo"
SOLUCIÓN:
  ├─ ¿El archivo es .json? (debe ser suic_password_backup_...)
  ├─ ¿Lo exportaste TÚ? (no debe estar modificado)
  └─ Ver GUIA_RAPIDA.md → Acciones de Emergencia

PROBLEMA: "Cambié de navegador y no me deja entrar"
SOLUCIÓN:
  ├─ ¿Tienes un backup? → 📤 Importar
  ├─ Primero este navegador pide crear contraseña
  ├─ Luego importas tu archivo del otro navegador
  └─ Recarga página → ingresa contraseña original ✅
