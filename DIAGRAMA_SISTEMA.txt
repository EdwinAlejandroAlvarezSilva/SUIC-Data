## Cronómetro - Preservación Exacta

```
Momento 1: Usuario inicia cronómetro
┌──────────────────┐
│ Cronómetro corre │ 00:00:00 ──▶ 00:01:30
│ 1:30 minutos     │
└──────────────────┘
         │
    Guarda en borrador:
    {
      elapsedSeconds: 90,
      running: true,
      lastStartTs: 1715081000000
    }

Momento 2: Usuario cierra navegador (sin perder tiempo)

Momento 3: Usuario reabre navegador días después
         │
         ▼
    Restaura:
    {
      elapsedSeconds: 90,      // ✅ 1:30 exacto
      running: false,           // Inicia en pausa
      lastStartTs: null
    }
         │
         ▼
    Cronómetro muestra: 00:01:30 ✅
    ¡SIN DESVIACIÓN!
```

## Componentes del Sistema

```
┌────────────────────────────────────────────────────────┐
│  draft-system-advanced.js (Sistema Principal)         │
├────────────────────────────────────────────────────────┤
│                                                         │
│  window.DraftSystem = {                                │
│    save()           // Guardar borrador                │
│    restore()        // Restaurar borrador              │
│    clear()          // Limpiar borrador                │
│    listAll()        // Listar todos                    │
│    getChronoState() // Obtener estado cronómetro      │
│    startAutoSave()  // Iniciar auto-guardado           │
│    stopAutoSave()   // Detener auto-guardado           │
│  }                                                      │
│                                                         │
└────────────────────────────────────────────────────────┘

┌────────────────────────────────────────────────────────┐
│  chrono-sync.js (Sincronización Cronómetro)           │

│                                                         │
│  window.ChronoSync = {                                 │
│    sync()       // Sincronizar ahora                   │

│    stop()       // Detener sincronización              │
│  }                                                      │
│                                                         │
```

## Eventos Disponibles

```
window.addEventListener('draft:saved', (evt) => {
  // Se disparó cuando se guardó un borrador
  const { draftId, timestamp } = evt.detail;
});

window.addEventListener('draft:restored', (evt) => {
  // Se disparó cuando se restauró un borrador
  const { draftId, timestamp } = evt.detail;
});

window.addEventListener('draft:cleared', (evt) => {
  // Se disparó cuando se limpió un borrador
  const { draftId } = evt.detail;
});
```
